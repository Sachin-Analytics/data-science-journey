# 🌍 Global Trade Analysis

An end-to-end Excel project on a global trade/order dataset — covering the full analytics workflow from raw data to a performance dashboard.

## 📌 Overview

Analyzed 500 global trade orders (2024–2025) across regions, product categories and customers. The workbook demonstrates every core Excel skill: data cleaning, formulas, lookups, conditional aggregation, pivot analysis, charts, macros and a final interactive dashboard.

## 📁 Files

| File | Purpose |
|------|---------|
| `Global_Trade_Dashboard.xlsx` | Full analysis workbook (solution) |
| `data/Global_Trade_Data.xlsx` | 500 orders — sales, profit, shipping, ship mode |
| `data/Product_Master.xlsx` | Product reference — category, supplier, origin country, unit cost |
| `data/Performance_Data.xlsx` | Monthly region performance — shipments & returns |
| `data/Region_Lookup.xlsx` | Region code → region name, continent, manager |

## 🛠️ Skills Demonstrated

- **Data Cleaning & Formatting** — standardized order table, consistent date/number formats
- **Formulas & Business Metrics** — Total Sales, Profit, Margin calculations
- **Text Parsing & ID Generation** — splitting names, generating customer codes with `LEFT` + `ROW`
- **Logical Classification** — `IF` / `AND` based performance flags
- **Lookups** — `VLOOKUP`, `INDEX` + `MATCH`, `IFERROR` (cross-workbook)
- **Conditional Aggregation** — `SUMIFS`, `AVERAGEIFS` by region/category
- **Pivot Tables** — monthly & yearly sales/profit trends, region breakdowns
- **Comparative Charts** — sales & profit visualizations
- **Macros** — recorded macro for table formatting/automation
- **Dashboard** — KPIs (total orders, sales, profit, avg margin), region & top-product views

## 📊 Key Insights

- Total sales (2024–25): **~$474K** | Total profit: **~$133K** | Avg profit margin: **~27%**
- Top regions by sales: Asia → Europe → North America
- Top products by profit: Denim Jacket and Travel Backpack

## 🎯 Conclusion

This project shows how a raw transactional dataset can be turned into a clean, analyzed, and dashboard-ready report using only Excel — from cleaning to insights.
