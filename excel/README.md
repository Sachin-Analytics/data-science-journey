# 📗 Excel Practice

My Excel practice projects — each file demonstrates specific spreadsheet skills I've learned.

## Files

### 1. Practice Set 1.xlsx — Data Validation & Conditional Formatting
- **Skills:** Data Validation (dropdowns, error messages), Conditional Formatting
- **Details:**
  - Region & Payment Status dropdowns
  - Highlighted defense values below average in red
  - Highlighted ages > 35 in green
  - Restricted sales entries to non-zero values

### 2. Practice Set 2.xlsx — Sorting, Filtering & Text Functions
- **Skills:** Sorting, Filtering, Text Functions, Date Operations
- **Details:**
  - Employee / Pokémon / customer datasets
  - Sorting by name and attack speed
  - Filtering with multiple conditions (type, stage, age, speed)
  - Counting empty cells, checking dates between ranges

### 3. Practice Set 3.xlsx — Lookups with VLOOKUP
- **Skills:** VLOOKUP, IFERROR, IF + AND, cross-sheet formulas
- **Details:**
  - Q1: VLOOKUP to retrieve each student's Science marks from the Term 1 Marks sheet
  - Q2: VLOOKUP to calculate attendance % for each student
  - Q3: Pass/Fail column using IF(AND(marks >= 70, attendance > 85%))
  - Used IFERROR to handle missing values (Backup Marks for student 107)

### 4. Practice Set 4.xlsx — Advanced Excel (13 questions)
- **Skills:** Pivot Tables, VLOOKUP, SUMIF/AVERAGEIF/COUNTIF, Conditional Formatting, Sorting, Filtering, Data Validation, Macros, Formulas
- **Details:**
  - Q1: Titanic dataset — raw data structuring
  - Q2: Conditional formatting on Fare (highlight Fare > average)
  - Q3: Sort Age column in descending order
  - Q4: Filter passengers on criteria (Not survived / Pclass)
  - Q5: Pivot table for average values (books dataset)
  - Q6: VLOOKUP to fetch Author name and Year from book name
  - Q7: Insert new column (User Rating) and populate using lookups
  - Q8: Find all movies released after a given date (Pixar films)
  - Q9: Calculate Total Price using multiplication formulas
  - Q10: SUMIF, AVERAGEIF, COUNTIF on sales/furniture data
  - Q11: Data validation on Sex column (only male/female allowed)
  - Q12: Create a Macro to format the table (standardized layout)
  - Q13: Test the macro output
